Status: research candidates qualified at the core-library level. The all-56
peer performance objective is **not established**. Production main remains
`56abf844fb07931370ef386ff724124dfa5d965c`.

The target is complete Xyce execution on the existing seven circuits, at 1/8
threads on LLC96/LLC32. Every candidate must retain default componentwise
accuracy and recovery. Promotion requires a replicated 2% improvement somewhere
with no greater than 2% linear-time or process-wall regression anywhere. Final
success requires a replicated 2% linear-time advantage over both CKTSO and
SubtreeLU in every setting. See [the campaign protocol](spice_campaign.md).

## Baseline diagnostics

The isolated coarse profiler restores byte-for-byte to main when its inserted
scopes are removed. All 28 settings were executed. Grid-drift diagnostics remain
separate from the upstream waveform acceptance protocol. Instrumentation and
overlap with diagnostic/build work exclude these measurements from acceptance.

An early eight-thread NEURON profile attributes about 196 ms to the mapped
refactor kernel, 106 ms to certificates, 40 ms to original-operator snapshots,
and 42 ms to solves within approximately 417 ms of combined API time. This
motivates the three isolated candidates; it does not predict their speedups.

An early eight-thread BJT profile instead attributes approximately 1.43 s of
caller-thread time to EGraph refactor execution and 391 ms to native transpose
solves within 1.96 s of combined API time. Snapshot and certificate costs are
smaller. A separate process-CPU sampler records 8,092 instruction samples, with
hotspots in column dispatch, batch updates, and dependency waits. Worker totals
overlap and must not be interpreted as additive wall time.

The previous `ca907ed` hybrid experiment's retained activation diagnostics
show that BJT builds a plan but rejects its parallel-work admission; the smaller
circuits fail the size threshold, and most NEURON calls take the existing compact
transpose route. No memory-cap failure was recorded. Reducing plan metadata
alone therefore would not address the observed lack of activation. The already
rejected prefix/live candidates are not presented as successful optimizations.

## Evidence and measurement status

Working evidence is under `/tmp/kls-spice-20261027`. It includes frozen sources,
link manifests, commands, session closure, all test logs, waveforms, failed
attempts, profiles, and a separately frozen campaign runner. The initial
126-observation plumbing run completed with every upstream waveform verifier
passing. Its stricter experimental grid gate and a changed runner file exclude
it from acceptance; its original runner bytes were recovered and hash-checked.

The finalized runner follows the established complete-circuit waveform protocol,
retains strict pointwise/grid diagnostics, measures child completion without
50 ms timeout-polling quantization, and refuses missing/duplicate/failed cells.
Fresh API campaigns precede four-pass paired timing. Only candidates passing
the initial gate receive an opposite-order confirmation. No initial timing,
single-cell result, aggregate speedup, or diagnostic activation establishes the
all-56 objective. Composition, final peer confirmation, and broad corpus
qualification remain contingent on those measured gates.
